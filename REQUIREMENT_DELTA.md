## 存量能力基线

- **CAP-001** Lumina can persist multiple provider configurations, select an active provider/model, manage custom providers through ACP, and switch the provider/model used by an active session.（证据：crates/lumina/src/config/providers.rs, ui/desktop/src/acp/providers.ts, crates/lumina/tests/acp_custom_provider_methods_test.rs, crates/lumina/tests/acp_custom_requests_test.rs）
- **CAP-002** Lumina creates, lists, reloads, and updates persistent sessions, including working directory, messages, provider/model state, and Lumina execution mode.（证据：crates/lumina/src/session/session_manager.rs, crates/lumina/tests/acp_server_test.rs, crates/lumina/tests/acp_custom_requests_test.rs）
- **CAP-003** Lumina opens a complete project directory, persists work items, runs, steps, checkpoints, and change sets, associates runs with sessions, and recovers interrupted work after restart.（证据：crates/lumina/src/project/service.rs, crates/lumina/tests/project_workspace.rs, ui/desktop/src/acp/__tests__/projects.test.ts）
- **CAP-004** The legacy migrator copies legacy configuration, desktop settings, and session databases into a Lumina target without modifying the source and converts legacy session fields and links.（证据：crates/lumina-legacy-migrator/src/lib.rs, crates/lumina-legacy-migrator/src/sqlite.rs, crates/lumina-legacy-migrator/tests/migration.rs）
- **CAP-005** Lumina includes local model discovery, download, registration, configuration and local inference paths, including native and emulated tool parsing.（证据：crates/lumina-local-inference/src/management.rs, crates/lumina-local-inference/src/backend.rs, crates/lumina-local-inference/src/local_model_registry.rs, ui/desktop/src/components/settings/localInference/LocalInferenceSettings.tsx）
- **CAP-006** Lumina provides MCP platform contracts and a desktop MCP center for discovery, managed entries, profiles, manual configuration and source policy.（证据：crates/lumina/src/mcp_platform/mod.rs, crates/lumina-sdk-types/src/custom_requests/mcp_platform.rs, ui/desktop/src/components/mcp-center/McpCenterView.tsx, ui/desktop/src/components/mcp-center/__tests__/SecurityBoundaries.test.tsx）
- **CAP-007** Lumina's Windows installer supports a custom program directory, in-place upgrade, separated governed data storage and retained upgrade backups.（证据：ui/desktop/installer/INSTALL_UPGRADE.md, ui/desktop/src/__tests__/windowsInstallerPolicy.test.ts, ui/desktop/src/utils/storageRootPolicy.ts）
- **CAP-008** Lumina exposes session tool discovery and tool permission configuration through its desktop ACP adapter.（证据：ui/desktop/src/acp/permissions.ts, ui/desktop/src/acp/permissionRequests.ts, crates/lumina-provider-types/src/permission.rs）
- **CAP-009** Lumina has a react-intl localization layer and a Simplified Chinese message catalog, but currently falls back to English when no locale or catalog is available.（证据：ui/desktop/src/i18n/index.ts, ui/desktop/src/i18n/messages/zh-CN.json, ui/desktop/src/i18n/i18n.test.ts）
- **CAP-010** Lumina contains an evidence database with schemas, projections, path guards and versioned storage primitives.（证据：crates/lumina-evidence-db/src/schema.rs, crates/lumina-evidence-db/src/store.rs, crates/lumina-evidence-db/src/path_guard.rs, crates/lumina-evidence-db/src/v2/store.rs）
- **CAP-011** Lumina exposes desktop views for Skills and Extensions and retains extension configuration paths.（证据：ui/desktop/src/components/skills/SkillsView.tsx, ui/desktop/src/components/extensions/ExtensionsView.tsx, ui/desktop/src/acp/extensions.ts）
- **CAP-012** Lumina contains Windows computer-controller code paths, but product-level browser and desktop control has not yet been proven by end-to-end acceptance evidence.（证据：crates/lumina-mcp/src/computercontroller/platform/windows.rs, crates/lumina-mcp/src/computercontroller/mod.rs）
