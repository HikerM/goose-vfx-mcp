Goose 本地模型与 MCP 桌面端使用说明

一、安装
1. 解压 Goose-custom-mcp-win32-x64-cuda-1.43.0.zip。
2. 进入解压后的 Goose-win32-x64 文件夹，双击 Goose.exe。
3. Windows 出现“未知发布者”提示时，选择“更多信息”→“仍要运行”。本包未做商业代码签名。

二、配置模型
1. 左下角“设置”→“本地推理”。
2. 在“Search ModelScope”输入模型名称，例如 Qwen3 GGUF。
3. 选择 GGUF 量化版本并下载。公开模型可直接搜索和下载，不需要登录 Hugging Face。
4. 下载卡片会显示进度、速度、预计剩余时间；网络短暂中断会显示自动重试次数并断点续传。
5. 下载完成后选择该模型，开始新聊天进行测试。

三、GPU / CPU 自动选择
1. NVIDIA GPU 且可用显存足以容纳模型及上下文时，程序自动用 GPU 加速。
2. 模型过大、显存不足或电脑没有可用 GPU 时，程序自动回退到 CPU，不会强行占满显存。
3. 默认上下文长度为 8192，避免首次加载时使用过大的上下文导致卡顿。
4. 不需要在另一台电脑单独安装 CUDA；带 NVIDIA 显卡的电脑安装最新显卡驱动即可。

四、配置 Custom stdio MCP
1. 点击左侧 MCP 图标，选择“手动”→“Custom stdio”。
2. 点击添加，填写名称、命令、参数、工作目录和需要的环境变量。
3. 保存后在“我的 MCP”中启用，再新建聊天测试工具调用。
4. 例：Python MCP 的命令可填写 py，参数填写 -m、你的模块名；若 Python 不在默认位置，可填写 python.exe 的完整路径。

五、fxhoudinimcp
1. 安装 64 位 Python 3.10 或更新版本，并安装与你的 Houdini 版本匹配的插件。
2. 在命令提示符执行：py -m pip install fxhoudinimcp
3. 执行：py -m fxhoudinimcp install，然后重启 Houdini。该命令会自动把 Houdini 插件安装到检测到的 Houdini packages 目录。
4. 执行：py -c "import sys; print(sys.executable)"，复制输出的 Python 完整路径。
5. 在 Custom stdio 中填写：命令为该 Python 完整路径；参数依次为 -m、fxhoudinimcp。
6. 如果 Houdini 使用的端口不是默认自动发现范围，在 MCP 环境变量中设置 HOUDINI_PORT 为与 Houdini 插件配置相同的端口；不要假设所有电脑的 Houdini 路径相同。

六、常见问题
1. 搜不到模型：确认网络能访问 modelscope.cn，搜索名称加上 GGUF。
2. 下载失败：先等待自动重试；持续失败时检查网络、磁盘剩余空间和模型是否为公开模型。
3. GPU 没有被用上：更新 NVIDIA 驱动；若模型大于可用显存，自动 CPU 回退是预期行为。
4. MCP 不可用：先在终端验证命令能启动，再复制完全相同的命令、参数和环境变量到 Custom stdio。
